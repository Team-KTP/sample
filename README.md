# 예시 코드 모음

아키텍처, 코드 컨벤션, 코드 스타일, 계층 구조를 코드로 읽고 이해하기 위한 샘플 저장소다.

샘플마다 브랜치를 하나씩 쓴다. `main`에는 이 목록만 둔다.

| 브랜치 | 내용 |
|---|---|
| [`ttadak`](../../tree/ttadak) | 따닥 서버의 아키텍처와 코드 스타일 예시 |

## 보는 방법

```bash
git clone -b ttadak https://github.com/Team-KTP/sample.git
```

## 새 샘플 추가

샘플끼리 코드가 섞이지 않도록 기록이 비어 있는 브랜치에서 시작하고, 위 목록에 한 줄을 더한다.

```bash
git switch --orphan <브랜치 이름>
```
