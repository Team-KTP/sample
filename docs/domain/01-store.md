# 01. 가게 (store)

- 상태: 제안 (AI가 제안. 샘플 전용의 가짜 정책이다. 따닥의 정책이 아니다)

이 문서는 샘플이 쓰는 말과 항상 참인 규칙이다. 서버의 `docs/domain/`과 같은 모양으로 썼다. 실제 정책은 위키가 정한다.

## 용어

| 한글 | 영어 | 뜻 |
|---|---|---|
| 상품 | Product | 팔 수 있는 물건. 이름, 설명, 재고, 가격, 배송 정책을 가진다 |
| 재고 | stock | 남은 상품의 개수 |
| 가격 | Price | 상품 하나의 금액(원) |
| 배송 정책 | ShippingPolicy | 배송비(원)와 출고 소요일 |
| 품절 | soldOut | 재고가 0인 상태 |
| 상품 등록 | register | 새 상품을 파는 목록에 올린다 |
| 가격 수정 | modifyPrice | 상품의 가격을 바꾼다. 이미 한 주문의 주문 금액은 바뀌지 않는다 |
| 주문 | Order | 상품 하나를 수량만큼 사겠다는 요청 |
| 주문하다 | place | 주문을 만든다 |
| 주문 항목 | OrderItem | 무엇을(상품) 얼마나(수량) 주문하는가 |
| 주문 취소 | cancel | 주문을 되돌린다 |
| 주문 금액 | totalPrice | 가격 × 수량 |
| 주문 상태 | OrderState | 주문됨(ORDERED), 취소됨(CANCELED) |
| 받는 사람 | Receiver | 이름, 연락처, 주소 |

## 규칙

| ID | 규칙 |
|---|---|
| R-1.1 | 가격은 0 이상이다 |
| R-1.2 | 상품의 이름은 비어 있을 수 없다 |
| R-1.3 | 등록할 때 재고는 0 이상이다 |
| R-1.4 | 재고가 0이면 품절이다 |
| R-1.5 | 주문 수량은 1 이상이다 |
| R-1.6 | 재고보다 많이 주문할 수 없다 |
| R-1.7 | 주문하면 재고가 주문 수량만큼 준다 |
| R-1.8 | 주문 금액은 가격 × 수량이다 |
| R-1.9 | 주문을 취소하면 재고가 주문 수량만큼 돌아온다 |
| R-1.10 | 이미 취소한 주문은 다시 취소할 수 없다 |
| R-1.11 | 여러 주문이 동시에 들어와도 재고는 음수가 되지 않는다 |
| R-1.12 | 상품의 설명은 비어 있을 수 없다 |
| R-1.13 | 배송비는 0 이상이다 |
| R-1.14 | 출고 소요일은 1 이상이다 |
| R-1.15 | 받는 사람의 이름, 연락처, 주소는 비어 있을 수 없다 |
